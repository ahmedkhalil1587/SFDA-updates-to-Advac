# SFDA ⇄ Advac HIS Compare

أداة HTML بتقارن أصناف مخزون أدفاك HIS مع ملفات SFDA الشهرية (الأدوية + الأعشاب/الصحي)، وبتطلع:

- أكواد SFDA القديمة اللي محتاجة تتحدث للكود الجديد (من عمود `oldRegisterNumber`)
- أكواد مقترحة من الباركود (GTIN) للأصناف اللي كودها فاضي أو غلط
- فروق سعر الجمهور (`SPRC6`): **مؤكدة** (حجم العلبة متأكد منه) و**للمراجعة**
- الباركود المختلف عن SFDA، والأكواد اللي مش موجودة في SFDA
- سكريبت SQL جاهز (backup + BEGIN TRAN / COMMIT) وتصدير Excel

كل المعالجة بتتم في المتصفح، ومفيش أي بيانات بتترفع.

## الاستخدام الشهري
1. صدّر ملف المخزون من أدفاك بالأعمدة دي:
   `ITM_CD, GTIN, RegisterNumber, Trade Name, ScientificCode, Public price, GenericOrBrand, ScientificName, shape, Quantity`
2. افتح الصفحة وارفع الملفات التلاتة (النظام بيتعرف على نوع كل ملف تلقائياً).
3. راجع التبويبات، وحدد بنود المراجعة اللي متأكد منها.
4. انسخ السكريبت أو حمّله، وشغّله على قاعدة البيانات.

## الملفات
- `index.html`: الواجهة
- `core.js`: منطق المقارنة وبناء SQL
